# Three-Phase-Induction-Motor-For-Water-Pumping-Applications

This project focuses on designing and evaluating a three-phase induction motor coupled with a centrifugal water pump, analyzing key performance metrics such as torque-speed characteristics, and speed-versus-flow-rate relationships using MATLAB simulations
